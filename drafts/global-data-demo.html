Global Data Assembler

This block fetches spreadsheet data authored in da.live and assembles it into the complete ro.json global-data structure — enabling content authors to manage data without developer involvement or da.live sheet-type errors.

How it works

  1. Author creates one spreadsheet per page in da.live under /global-data/ro/
  2. Each row in the spreadsheet = one entry in globalDataMap['global-data']
  3. A manifest spreadsheet (pages.json) lists all page names
  4. This block fetches the manifest + all page sheets in parallel and assembles the nested JSON
  5. Result is stored in window.globalData for other blocks to consume
